# 01. 요구사항 (2026-10-22 회의)

근거: 10/22 회의 녹음 1번(약 60분). 시각은 녹음 1번 시작 기준입니다.
회의 발언을 옮긴 것이며, 확정 사양서는 아닙니다.

## 과제 배경

| 항목 | 내용 | 녹음 위치 |
|---|---|---|
| 용도 | 테더 드론의 유선이 끊겼을 때 비면허 대역(5GHz/2.4GHz) 무선으로 영상을 계속 받기 | 01:06~02:11 |
| 거리 | 최소 100m에서 시작, 최종 7~10km 검토. 7km급은 지연보다 연결 유지가 중요 | 00:01~01:05 |
| 핵심 문제 | 통신이 끊겼다 다시 붙을 때 복구 지연이 길다. AP·TCP/IP 방식으로는 감당 못 함 | 02:12~03:12 |
| 무선 방식 | WFB-ng (핸드셰이크 없이 모니터 모드로 패킷을 직접 뿌리고 받음), OpenIPC 장비 | 15:13~18:46 |
| 대역 사용 | 2.4GHz 데이터, 5GHz 영상, 900MHz 백업 (일반적인 설계) | 31:20~31:50 |

- 드론 탑재 보드는 무게·전력 때문에 AGX가 아니라 Orin NX급 (06:59~09:42)
- 하드웨어 인코더가 있어야 초저지연이 나옴. 라즈베리파이 5는 인코더가 없어 제외 (09:16~10:10)
- Insta360 X3는 USB로 영상을 받는 데만 약 300~400ms 지연 (14:00~15:11, 42:01~42:31)
- 360 카메라는 220도 렌즈, 180도만 쓰고 나머지는 겹침용 (48:19~48:45)
